# Product Context

## Зачем существует этот проект

Люди постоянно сталкиваются с необходимостью запоминать дела: работу, бытовые задачи, идеи. Бумажные заметки теряются, 
а полноценные таск-менеджеры (Jira, Asana) перегружены для личного использования. Этот проект решает проблему 
«простого списка дел, который всегда под рукой и не требует обучения».

## Какую проблему решаем

- **Потеря задач**: пользователь забывает о делах, потому что они не записаны в одном месте.
- **Перегрузка инструментов**: существующие решения требуют настройки, интеграций,
  командной работы — всё это избыточно для одного человека.
- **Отсутствие контроля**: пользователь не видит, что сделано, а что ещё в процессе.

## Для кого этот продукт

- **Основной пользователь**: один человек, который ведёт личные дела.
- **Контекст использования**: дома или на работе, с десктопа или ноутбука.
- **Уровень технической подготовки**: не требует специальных знаний.

## Ключевые сценарии использования

1. **Утро**: пользователь открывает приложение, видит список активных задач на день.
2. **В течение дня**: добавляет новые задачи по мере поступления, отмечает выполненные.
3. **Вечер**: просматривает, что сделано, планирует задачи на завтра.

## Как продукт должен ощущаться
- **Простой**: никаких лишних кнопок, настроек, интеграций.
- **Быстрый**: задача создаётся за 2-3 секунды, без перезагрузки страницы.
- **Надёжный**: данные не теряются, даже если пользователь закрыл браузер.
- **Личный**: только владелец видит свои задачи.

## Ключевые бизнес-объекты

### Task
Задача пользователя. Имеет заголовок, описание, статус (активная / выполненная),
приоритет и даты создания/обновления. Задача принадлежит ровно одному пользователю.

## Инварианты (что всегда должно быть верно)
- Выполненная задача не может быть отредактирована (только возвращена в активные или удалена).

## Чего продукт НЕ делает
- Не поддерживает совместную работу над задачами.
- Не отправляет напоминания и уведомления.
- Не имеет мобильного приложения.
- Не интегрируется с календарями и другими сервисами.
- Не поддерживает подзадачи и вложенные списки.

## Критерии успеха продукта
- Пользователь может начать работу без инструкции.
- Создание задачи занимает не более 3 секунд.
- Пользователь возвращается в приложение на следующий день (retention).
- Данные не теряются при перезапуске приложения.
